# Fleet transport work

The 2018 transport work of each IMO ship type and size bin, and the IMO bins each ship class of the paper (`data/ship_classes.csv`) stands for. The class and fleet-weight steps of the paper read both.

## Source

IMO, Fourth IMO GHG Study 2020, Table 35 (ships, dwt, distance and CO2 per type and size bin) and Table 60 (EEOI and AER), year 2018: https://www.imo.org/en/OurWork/Environment/Pages/Fourth-IMO-Greenhouse-Gas-Study-2020.aspx

## Files

| File                                       | Content                                                                                            |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| `imo_ghg4_transport_work_by_type_size.csv` | 2018 transport work by ship type and size bin: CO2 of the bin over its mean EEOI, in tonne-nm      |
| `fleet_work_bins.csv`                      | IMO type and size bin of each ship class of the paper                                              |
